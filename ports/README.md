# ports/: native builds of the decompilation

Downstream of the decomp. The decomp's C (`src/stuntracefx`) is the game
itself and no port copies or edits it: a native build is that C as a
cartridge, played on the nativeshvc console library (a separate project,
checked out beside this one as `../nativeshvc`).

| folder | what |
|---|---|
| `stuntracefx/front` | the cartridge for nativeshvc: its description (`main.c`, `cart.c`), its Super FX on nativeshvc's chip connector (`superfx_cart.c`), its cost profile (`cost_profile.c`, generated by nativeshvc's `tools/nshvc-profile`), touch and art, and the build (`build.sh`; `package_app.sh` and `package_ios.sh`, the macOS and iOS apps) |
| `stuntracefx/icon` | the game's icon (`icon.jpg`, the box art's title) and `icons.sh`, which makes each platform's form of it: macOS `.icns`, the iOS asset catalog, the Windows `.ico` (built into every Windows exe) |
| `common/snes` | the cartridge's Super FX (`superfx.c`); the rest is the first port's own console model, superseded by nativeshvc |
| `common/host` | the first port's platform layer, superseded by nativeshvc's hosts |
| `stuntracefx` | the first port's runtime and build (`link.sh`, `PORT.md`), superseded; `PLAN.md`, `HANDOFF.md`, `WIDESCREEN.md` |

```sh
sh ports/stuntracefx/front/build.sh                         # headless
OUT=build/stuntracefx/front/macos NSHVC_BUILD=build/macos \
  LIBS="-framework Cocoa -framework QuartzCore -framework AudioToolbox -framework CoreAudio -framework GameController -framework Metal -framework Foundation" \
  sh ports/stuntracefx/front/build.sh                       # a macOS window
sh ports/stuntracefx/front/package_app.sh                   # the macOS app, with its icon
build/stuntracefx/front/null/stuntracefx --script PLAY --headless --out DIR
```
